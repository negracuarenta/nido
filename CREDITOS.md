# Créditos de las fotos

Todas las imágenes tienen licencia libre y están descargadas al repositorio: el sitio
no enlaza archivos alojados en otros servidores. Se reescalaron a 1600 px de ancho
máximo y se guardaron en WebP.

El epígrafe de cada foto en la web muestra «título · autor · licencia · fuente».
